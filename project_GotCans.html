Project Overview

Project Description:

Designed and developed a full web presence for Got Cans, a community-driven recycling initiative founded by two college students. The service provides convenient bottle and can pickups, with 10% of proceeds donated to charity and the rest funding educational goals. My contributions included:

Custom Domain & GitHub: Set up a custom domain and public GitHub repo, managing deployment and visibility settings to maintain professionalism while keeping version control

My Role:

Website Creation: Built a responsive single-page website (hosted via GitHub Pages) that outlines the service’s mission, process, and contact options. Ensured clear calls to action and an accessible user experience.

Visual Identity: Designed the brand logo, color palette, and visual assets using Canva and Adobe tools, aiming for a clean, approachable, and eco-friendly aesthetic.
